**Goal:** Replace the Python phase1/-phase7/ implementation with a single TypeScript Node.js 20 project rooted at `index.ts`, preserving byte-for-byte wire-protocol parity, and finish with a live-tested OpenAI + Anthropic compatible proxy that works with Claude Code and Codex child sessions without touching the user's real Anthropic auth.

**Architecture:** `index.ts` → `src/server/start.ts` (Hono) → per-request `HatchClient` that opens a Noise-encrypted WebSocket via `cycletls`, runs the Phase 4+5 chat flow (`/client/register-capabilities` → `/chat/subscribe` → `/chat/stream`), streams `delta.text_append` events back to the OpenAI/Anthropic SSE adapter. Noise XX hand-rolled on `@noble/*`. Protobuf messages built dynamically from `.binpb` descriptors via `protobufjs`.

**Tech Stack:** Node 20 LTS, TypeScript strict + ESM, hono + @hono/node-server, cycletls, protobufjs, @noble/curves + @noble/ciphers + @noble/hashes, pino, zod, tsx.

**Spec:** [docs/specs/02-10-2026-node-port-design.md](../specs/02-10-2026-node-port-design.md)

## Global Constraints

- Runtime: Node 20 LTS. TypeScript strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`. ESM only (`"type": "module"` in package.json). Zero `any` in checked-in code.
- Noise suite literal: `Noise_XX_25519_AESGCM_SHA256`. msg1 payload = `0x0a 0x20` + 32 CSPRNG bytes. msg3 payload = empty for standard VMs. AES-GCM nonce = 4 zero bytes + big-endian u64 counter.
- NoiseTransportFrame max chunk payload: 48 KB (`MAX_CHUNK_PAYLOAD = 48 * 1024`). Server-side cap is 65535B; we leave headroom.
- Chrome TLS fingerprint via cycletls, UA pinned to `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/154.0.0.0 Safari/537.36`. `sec-ch-ua-platform: "Windows"`.
- Env vars: `MUSE_PROXY_KEY`, `MUSE_PROXY_MODEL`, `MUSE_SESSION_PATH`, `MUSE_STORAGE_STATE_PATH`, `MUSE_PROXY_PORT`, `MUSE_PROXY_HOST`, `MUSE_TZ`, `LOG_LEVEL`. All validated at startup via zod.
- cycletls child process must be shut down on SIGTERM / SIGINT / `uncaughtException` via `await tls.exit()`.
- One `cycletls` instance per `HatchClient`; `HatchClient` is per-request (fresh Noise session per API call).
- No file writes outside `./session.json` (bootstrap output) and `./logs/` (if enabled). No writes to `~/.claude/`.

## Review Focus

1. **Empty / malformed `messages` array** on `POST /v1/chat/completions` or `POST /v1/messages` must return HTTP 400 with a JSON error, never 500 or a hang. Pinned in Task 15's tests.
2. **User message > 48 KB** (common when Claude Code sends system prompt + MCP tools) must chunk correctly across multiple NoiseTransportFrames and be reassembled server-side. Pinned in Task 9's chunking test with a 100 KB payload.
3. **SIGTERM mid-request** must trigger `cycletls.exit()` AND the in-flight request returns a 503 (not a crash). Pinned in Task 10's lifecycle test.
4. **Missing `session.json` + bootstrap fails** (expired cookie, no `storage_state.json`) must return HTTP 503 with a clear error pointing at `npm run bootstrap`, never crash-loop the Node process. Pinned in Task 13's auto-rebootstrap test.
5. **Client disconnects mid-SSE stream** must not leak the WebSocket; Hatch's in-flight request completes but the response generator exits cleanly. Pinned in Task 16's SSE test.

```ts
import { gcm } from "@noble/ciphers/aes";

export function noiseNonce(n: bigint): Uint8Array {
  const out = new Uint8Array(12);
  const view = new DataView(out.buffer);
  view.setUint32(4, Number(n >> 32n) & 0xffffffff, false);
  view.setUint32(8, Number(n & 0xffffffffn), false);
  return out;
}

export class CipherState {
  nonce = 0n;
  constructor(private readonly key: Uint8Array) {
    if (key.length !== 32) throw new Error(`CipherState key must be 32 bytes, got ${key.length}`);
  }
  encrypt(ad: Uint8Array, pt: Uint8Array): Uint8Array {
    const ct = gcm(this.key, noiseNonce(this.nonce), ad).encrypt(pt);
    this.nonce++;
    return ct;
  }
  decrypt(ad: Uint8Array, ct: Uint8Array): Uint8Array {
    const pt = gcm(this.key, noiseNonce(this.nonce), ad).decrypt(ct);
    this.nonce++;
    return pt;
  }
}
```

```ts
import { sha256 } from "@noble/hashes/sha256";
import { hmac } from "@noble/hashes/hmac";
import { CipherState } from "./cipher.ts";

function hkdf(ck: Uint8Array, ikm: Uint8Array, outs: 2 | 3): Uint8Array[] {
  const tempKey = hmac(sha256, ck, ikm);
  const o1 = hmac(sha256, tempKey, Uint8Array.of(1));
  const o2 = hmac(sha256, tempKey, concat(o1, Uint8Array.of(2)));
  if (outs === 2) return [o1, o2];
  const o3 = hmac(sha256, tempKey, concat(o2, Uint8Array.of(3)));
  return [o1, o2, o3];
}
function concat(a: Uint8Array, b: Uint8Array): Uint8Array {
  const r = new Uint8Array(a.length + b.length); r.set(a); r.set(b, a.length); return r;
}

export class SymmetricState {
  h: Uint8Array; ck: Uint8Array; cipher: CipherState | null = null;
  constructor(protocolName: string) {
    const name = new TextEncoder().encode(protocolName);
    if (name.length <= 32) {
      this.h = new Uint8Array(32); this.h.set(name);
    } else {
      this.h = sha256(name);
    }
    this.ck = this.h.slice();
  }
  mixHash(data: Uint8Array): void {
    this.h = sha256(concat(this.h, data));
  }
  mixKey(ikm: Uint8Array): void {
    const [ck, k] = hkdf(this.ck, ikm, 2);
    this.ck = ck;
    this.cipher = new CipherState(k);
  }
  encryptAndHash(pt: Uint8Array): Uint8Array {
    const out = this.cipher ? this.cipher.encrypt(this.h, pt) : pt;
    this.mixHash(out);
    return out;
  }
  decryptAndHash(ct: Uint8Array): Uint8Array {
    const pt = this.cipher ? this.cipher.decrypt(this.h, ct) : ct;
    this.mixHash(ct);
    return pt;
  }
  split(): { c1: CipherState; c2: CipherState } {
    const [k1, k2] = hkdf(this.ck, new Uint8Array(), 2);
    return { c1: new CipherState(k1), c2: new CipherState(k2) };
  }
}
```

```ts
import { SymmetricState } from "./symmetric.ts";
import { CipherState } from "./cipher.ts";
import { generateKeyPair, dh, type KeyPair } from "./curve.ts";

const PROTOCOL = "Noise_XX_25519_AESGCM_SHA256";

export class XxInitiator {
  private ss: SymmetricState;
  private e: KeyPair | null = null;
  private s: KeyPair;
  private re: Uint8Array | null = null;
  private rs: Uint8Array | null = null;
  private phase: 0 | 1 | 2 | 3 | 4 = 0;

  constructor(prologue: Uint8Array = new Uint8Array(), staticKey?: KeyPair) {
    this.ss = new SymmetricState(PROTOCOL);
    this.ss.mixHash(prologue);
    this.s = staticKey ?? generateKeyPair();
    this.phase = 1;
  }

  writeMessage1(payload: Uint8Array): Uint8Array {
    if (this.phase !== 1) throw new Error("XX: wrong phase for writeMessage1");
    this.e = generateKeyPair();
    this.ss.mixHash(this.e.pub);
    const encPayload = this.ss.encryptAndHash(payload);  // no cipher yet, no-op
    this.phase = 2;
    return concat(this.e.pub, encPayload);
  }

  readMessage2(msg: Uint8Array): Uint8Array {
    if (this.phase !== 2) throw new Error("XX: wrong phase for readMessage2");
    if (msg.length < 96) throw new Error(`msg2 too short (${msg.length} < 96)`);
    if (!this.e) throw new Error("XX: missing e");
    this.re = msg.slice(0, 32);
    this.ss.mixHash(this.re);
    this.ss.mixKey(dh(this.e.priv, this.re));
    this.rs = this.ss.decryptAndHash(msg.slice(32, 32 + 32 + 16));  // 48 bytes = enc static
    this.ss.mixKey(dh(this.e.priv, this.rs));
    const payload = this.ss.decryptAndHash(msg.slice(32 + 48));
    this.phase = 3;
    return payload;
  }

  writeMessage3(payload: Uint8Array): {
    bytes: Uint8Array;
    split: { send: CipherState; recv: CipherState };
    remoteStatic: Uint8Array;
    handshakeHash: Uint8Array;
  } {
    if (this.phase !== 3) throw new Error("XX: wrong phase for writeMessage3");
    if (!this.re || !this.rs) throw new Error("XX: missing re/rs");
    const encS = this.ss.encryptAndHash(this.s.pub);
    this.ss.mixKey(dh(this.s.priv, this.re));
    const encPayload = this.ss.encryptAndHash(payload);
    const { c1, c2 } = this.ss.split();
    this.phase = 4;
    return {
      bytes: concat(encS, encPayload),
      split: { send: c1, recv: c2 },
      remoteStatic: this.rs,
      handshakeHash: this.ss.h,
    };
  }
}

function concat(a: Uint8Array, b: Uint8Array): Uint8Array {
  const r = new Uint8Array(a.length + b.length); r.set(a); r.set(b, a.length); return r;
}
```

```ts
export const MAX_CHUNK_PAYLOAD = 48 * 1024;

export function buildTransportFrames(chunkId: bigint, serviceRequestBytes: Uint8Array): Uint8Array[] {
  const parts: Uint8Array[] = [];
  const len = serviceRequestBytes.length;
  const total = len === 0 ? 1 : Math.ceil(len / MAX_CHUNK_PAYLOAD);

    const msg: NoiseTransportFrame = { chunkId, chunkIndex: i, totalChunks: total, payload: slice };
    parts.push(T.encode(T.create(msg)).finish());
  }
  return parts;
}
```

- [ ] **Step 2: Implement**

```ts
interface ContentBlock { type: string; text?: string; }
interface Message { role: string; content: string | ContentBlock[]; }

export function flattenMessages(messages: Message[]): string {
  const out: string[] = [];
  for (const m of messages) {
    const text = typeof m.content === "string" ? m.content : m.content.filter(b => b.type === "text").map(b => b.text ?? "").join("");
    if (!text.trim()) continue;
    if (m.role === "system") out.push(`[system]\n${text}`);
    else if (m.role === "assistant") out.push(`[assistant previous turn]\n${text}`);
    else out.push(text);
  }
  return out.join("\n\n");
}
```

### Task 18: Auto re-bootstrap + request handler wiring

**Files:**
- Create: `src/server/handler.ts`
- Modify: `src/server/openai.ts`, `src/server/anthropic.ts` (use handler), `src/server/start.ts`
- Test: `tests/server-handler.test.ts`

**Interfaces:**
- Produces: `runChat(userText, timezone, onDelta?): Promise<{replyText, messageId}>` that opens a fresh HatchClient, retries once with `bootstrap()` on first open failure, returns the result.

- [ ] **Step 1: Implement**

```ts
import { bootstrap } from "../bootstrap/session.ts";
import { HatchClient } from "../hatch/client.ts";
import { sendAndCollectReply } from "../hatch/chat.ts";
import { getTls } from "../hatch/tls.ts";
import { readFileSync } from "node:fs";
import type { Config } from "../config.ts";
import type { Session } from "../bootstrap/session.ts";
import { logger } from "../log.ts";

async function loadSession(path: string): Promise<Session> {
  return JSON.parse(readFileSync(path, "utf-8")) as Session;
}

export async function runChat(cfg: Config, userText: string, onDelta?: (t: string) => void): Promise<{ replyText: string; messageId: string }> {
  const tls = await getTls();
  for (let attempt = 0; attempt < 2; attempt++) {
    try {
      const session = await loadSession(cfg.sessionPath);
      const client = await HatchClient.open(session, tls);
      try {
        const { replyText, messageId } = await sendAndCollectReply({ client, userText, timezone: cfg.timezone, listenMs: 60_000, onDelta });
        return { replyText, messageId };
      } finally {
        await client.close();
      }
    } catch (e) {
      logger.warn({ err: (e as Error).message, attempt }, "HatchClient open/run failed");
      if (attempt === 0) {
        try { await bootstrap({ storageStatePath: cfg.storageStatePath, sessionPath: cfg.sessionPath }); } catch (b) { throw new Error(`bootstrap failed: ${(b as Error).message}`); }
        continue;
      }
      throw e;
    }
  }
  throw new Error("unreachable");
}
```
